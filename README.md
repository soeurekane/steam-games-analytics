# Steam Games Analytics

Учебный аналитический проект о рынке игр в Steam. В нём реализован полный путь работы с данными: получение через API, очистка и преобразование, проектирование реляционной базы SQLite, анализ с помощью SQL и Python, а также визуализация результатов.

## Цель проекта

Исследовать выборку игр Steam и ответить на вопросы:

- как распределены цены платных игр;
- какие жанры встречаются чаще всего;
- как различается средняя цена между жанрами;
- чем отличаются бесплатные и платные игры по числу рекомендаций;
- какие разработчики и издатели представлены в выборке чаще других.

## Источники и сбор данных

Список приложений для выборки был получен через **SteamSpy API**, а подробная информация по каждому `appid` — через **Steam Store API**. В итоговый набор включались только объекты с типом `game`; DLC и другой контент отсеивались.

Для каждой игры собирались:

- идентификатор и название;
- признак free-to-play и возрастное ограничение;
- разработчики, издатели и жанры;
- число рекомендаций;
- дата выхода;
- поддержка Windows, macOS и Linux;
- цена и валюта.

Во время длительных запросов промежуточные результаты сохранялись в CSV, поэтому сбор можно было контролировать без потери уже полученных данных.

## Подготовка данных

Перед анализом данные прошли несколько этапов подготовки:

1. Удаление повторов по `appid`. Если для одной игры было несколько записей, сохранялась наиболее полная.
2. Проверка явных и скрытых пропусков в разработчиках, издателях, жанрах, датах и ценах.
3. Замена некорректной нулевой цены у платных игр на пропуск.
4. Приведение дат релиза разных форматов и локалей к единому типу `datetime`.
5. Повторное получение цен для региона США (`cc=us`) и нормализация валюты в USD.
6. Приведение числовых, логических и текстовых полей к подходящим типам.

После очистки в датасете осталось **906 уникальных игр**.

## Структура базы данных

Очищенные данные сохранены в `steam_games.db`. База приведена к реляционной структуре из семи таблиц:

| Таблица | Содержание |
|---|---|
| `games` | Основные характеристики игр: `appid`, название, цена, валюта, дата релиза, рекомендации и платформы |
| `genres` | Справочник жанров |
| `game_genres` | Связь многие-ко-многим между играми и жанрами |
| `developers` | Справочник разработчиков |
| `game_developers` | Связь многие-ко-многим между играми и разработчиками |
| `publishers` | Справочник издателей |
| `game_publishers` | Связь многие-ко-многим между играми и издателями |

Такое разделение исключает повторение названий жанров, разработчиков и издателей в основной таблице и позволяет выполнять анализ с помощью `JOIN`, агрегирования и группировки.

## Анализ

В проекте используются оба подхода:

- **SQL** — выборки из SQLite, соединение таблиц, подсчёт игр, средних значений и рейтингов;
- **Python/pandas** — расчёт медиан, дополнительная проверка данных и подготовка результатов к визуализации.

В ноутбуке исследованы распределение и выбросы цен, популярность жанров, средняя цена по жанрам, рекомендации бесплатных и платных игр, а также наиболее часто встречающиеся разработчики и издатели.

## Ключевые результаты

- В итоговой базе — **906 игр**: 768 платных и 138 бесплатных.
- Средняя цена платной игры с доступной ценой — **$23.11**, медианная — **$19.99**.
- Распределение цен имеет правостороннюю асимметрию: сравнительно небольшая группа дорогих игр повышает среднее значение.
- Самый распространённый жанр — **Action** (612 игр), далее идут **Adventure** (345) и **Indie** (330).
- В выборке средняя цена составляет около **$21.32** для RPG, **$20.41** для Adventure, **$20.08** для Action и **$13.45** для Indie.
- Среднее число рекомендаций чувствительно к отдельным хитам. Поэтому для сравнения групп важна медиана: около **38 919** у платных игр и **334** у бесплатных.

> Результаты относятся к собранной выборке и не описывают весь каталог Steam. Цены также зависят от региона и момента запроса.

## Как запустить проект

### 1. Клонировать репозиторий и перейти в папку

```bash
git clone <URL-репозитория>
cd steam_analysis
```

### 2. Создать и активировать виртуальное окружение

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

### 3. Установить зависимости

```bash
python -m pip install -r requirements.txt
```

### 4. Открыть ноутбук

```bash
jupyter notebook steam_games_analysis.ipynb
```

Запустите ячейки по порядку. Готовая база `steam_games.db` и CSV-файлы уже находятся в проекте, поэтому SQL-анализ можно изучать без повторного выполнения длительного сбора через API.

> Для полного пересбора данных нужен доступ к интернету. Запросы выполняются последовательно с паузами, поэтому этот этап может занять продолжительное время.
